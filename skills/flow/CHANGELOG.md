# Changelog

One entry per `jorekai-flow` version. The version at the top equals `version` in `skills/flow/.claude-plugin/plugin.json`; `scripts/check.sh` checks that. Dates are ISO.

## 0.1.0 (2026-10-13)

- Added: the theme and its router, `jorekai-flow:flow`.
- Added: `jorekai-flow:go`, a grant to work until the goal is met, or for one step with `1`.
- Added: `jorekai-flow:resume`, the previous session of this project as goal, state, and open items.
- Added: `jorekai-flow:ship`, test, commit, push, merge on green, deploy, and prove the result.
- Added: `jorekai-flow:watch`, a condition checked in the background and a notice when it holds.
- Added: `jorekai-flow:status`, background work, branch, pull requests, checks, and blockers in one table.
- Added: `jorekai-flow:handoff`, a prompt a new session can start from, placed on the clipboard.
